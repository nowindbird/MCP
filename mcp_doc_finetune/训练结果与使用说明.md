# MCP 代码→文档微调模型 — 训练结果与使用说明

> 训练日期：2026-09-30 ｜ 基座：Qwen2.5-3B-Instruct ｜ 方法：QLoRA 4bit + LoRA (r=16, α=32)

## 1. 成果概览

| 项 | 值 |
|---|---|
| 正式训练语料 | 541 条（564 个 MCP 工具去重，来自 50+ 真实仓库代码 AST 提取） |
| 其中含敏感行为事实 | 34 条（file/network/subprocess/env/混淆等硬事实） |
| 训练配置 | 3 epochs × 204 步，batch=1，grad_accum=8，max_len=2048，lr=2e-4 cosine |
| 训练时长 | ~34 分钟（RTX 4060 Laptop 8GB，峰值显存 7.9GB） |
| 最终 train_loss | **0.034**（收敛良好） |
| LoRA 权重 | adapter_mcp_doc/adapter_model.safetensors（**117 MB**） |

## 2. 能力验证结果

**格式与内容能力（已验证 ✅）**
- name / description / input_schema / security_declarations 四字段 JSON 结构输出稳定
- input_schema 从函数签名推导完整正确（含 required 列表）
- description 正确取自 docstring
- 训练集内样本：模型输出与 ground truth 完全一致

**安全声明召回（有局限 ⚠️，见下）**
- held-out 恶意样本测试（保存笔记却用 curl 外传 + 硬编码密钥）：
  - 模型正确输出 JSON 骨架，但 **network / hidden_flags 漏标**（外传与硬编码凭据未声明）
  - 根因：正式语料 541 条中 34 条敏感多为安全研究工具，**真实投毒样本几乎缺席**，模型未学到恶意模式声明

## 3. 局限与迭代路径

| 问题 | 根因 | 迭代方案 |
|---|---|---|
| 恶意行为声明召回低 | 语料缺少投毒样本 | ① 补充投毒扫描检出的 2 个 suspicious 仓库代码 + 论文 Table 9 14 模式构造的恶意样本（冒烟语料已有 6 条）；② 恶意:良性 1:4 混合重训 |
| 长样本截断 | max_len=2048 < 个别 2.4 万字符样本 | 提高 max_len 或按函数切分样本 |
| 提取器覆盖 | 部分网络调用（python-nmap 等）未被识别 | build_dataset.py 增加调用模式 |

## 4. 使用方式

```powershell
# 推理：对单个 .py 或整个目录生成结构化文档（JSON 打印到 stdout）
.\venv\Scripts\python.exe infer_mcp_doc.py --model_dir "models\Qwen2.5-3B-Instruct" --adapter_dir "adapter_mcp_doc" --code-file ".\demo_tool.py"

# 批量写文件
.\venv\Scripts\python.exe infer_mcp_doc.py --model_dir "models\Qwen2.5-3B-Instruct" --adapter_dir "adapter_mcp_doc" --code-file ".\mcp插件\某仓库" --out "docs.jsonl"

# 重新训练（补样本后）
.\venv\Scripts\python.exe train_lora.py --model_dir "models\Qwen2.5-3B-Instruct" --data "dataset_real_v2.jsonl" --output_dir "adapter_mcp_doc_v2" --epochs 3 --grad_accum 8 --max_len 2048
```

## 5. 关键文件

| 文件 | 说明 |
|---|---|
| `adapter_mcp_doc/` | LoRA 权重（117MB，adapter_model.safetensors + config + tokenizer） |
| `train_lora.py` | 训练脚本（QLoRA/LoRA，--max_steps 链路验证，--quantize 4bit/8bit/none） |
| `infer_mcp_doc.py` | 推理脚本（加载基座+adapter，单文件/目录批量生成） |
| `build_dataset.py` | 语料提取（AST 确定性提取，论文 14 模式敏感行为） |
| `dataset_real.jsonl` | 正式训练语料 541 条 |
| `dataset_smoke.jsonl` | 冒烟语料 14 条（8 良性 + 6 恶意，用于链路验证与 held-out 测试） |
| `train_real.log` | 正式训练完整日志（含 loss 曲线） |
| `MCP文档微调方案.md` | 方案总文档（数据管线/训练/评测/风险） |
